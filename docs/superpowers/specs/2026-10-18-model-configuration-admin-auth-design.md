# 模型参数与管理员访问控制设计规格

## 状态与范围

状态：待用户审阅。

本规格为现有 Vercel + Neon 商品研究网站增加管理员登录、模型参数配置和定时任务入口。登录与访问控制覆盖整个应用及其数据 API，避免现有商品数据接口继续匿名开放。

本期交付：

1. 单管理员账号登录与退出，保护全部业务页面和 API。
2. 「配置」导航分组，包含「模型参数」和「定时任务」。
3. 模型参数页面：通过卡片管理 OpenAI-compatible 大模型配置，支持新增、查看、修改、启停、设为默认、连接测试和删除。
4. 定时任务页面：提供明确的未启用状态和功能说明，不执行或伪造定时任务。
5. 模型配置及登录限流状态持久化在 Neon；密码、会话签名密钥和 API Key 加密密钥保存在服务端环境变量。

本期不包含：模型对话/分析调用、按优先级自动路由或故障转移、自动冷却机制、任务调度器、多个管理员/角色/注册流程、SSO、密码重置页面、API Key 轮换界面。

## 已确认的产品决定

- 大模型配置由管理员登录后维护。
- API Key 使用 AES-256-GCM 在服务端加密后存入 Neon；浏览器永远拿不到原始密钥。
- 新建模型配置必须提供 API Key；编辑时留空表示保留原密钥，替换密钥需要明确输入新值。
- 连接测试由服务端发起，仅在管理员点击「测试」后执行。
- 商品数据、模型配置及登录失败限流记录等应用状态保存在 Neon。认证凭据和加密密钥属于服务端秘密，保存在本地 `.env.local` 或 Vercel 环境变量中，不写入数据库或 Git。
- 当前选择单管理员模式，暂不建设用户管理、角色和注册。
- 「定时任务」先作为导航和空状态页面，不代表调度功能已经可用。

## 目标与用户流程

管理员从登录页进入网站，登录后访问左侧业务导航。打开「配置 → 模型参数」后，可以新建模型服务配置，填写服务名称、OpenAI 兼容接口地址、模型标识、API Key、优先级、超时时间和深度思考设置。保存后以卡片查看已脱敏的配置，并可测试连接、编辑、启用/停用、设为默认或删除。

连接测试显示成功或可读的失败原因，并记录最近测试状态和时间。卡片上的「冷却至」是运行状态展示位；由于本期尚无模型调用和自动冷却机制，显示「—」，不允许手动编辑，也不伪称已有冷却行为。

## 页面与导航

### 应用框架

- 保留左侧导航栏和右侧主内容区；移动端使用可展开抽屉。
- 导航新增可展开「配置」分组，包含「模型参数」和「定时任务」。当前路由及子路由应正确高亮。
- 新增登录页和退出入口；未登录访问业务页面时跳转到登录页，登录成功后返回原目标页面。
- 登录页不展示商品、模型配置或任何密钥信息。

### 模型参数页

- 页面标题「模型参数」，说明模型服务连接参数集中保存在 Neon，密钥仅服务端可解密。
- 顶部提供「添加模型」按钮；未配置模型时显示真实空状态。
- 模型以响应式卡片呈现：宽屏双列或多列，窄屏单列；沿用项目浅灰工作区、白色圆角卡片和蓝色强调色。视觉参考用户提供的模型卡片截图，不复刻外部品牌标识。
- 卡片显示：配置名称/提供方、默认标记、可用或未测试状态、API Base URL、模型名称、脱敏 API Key（只显示掩码和末四位）、优先级、超时（秒）、深度思考开关、最近测试时间及只读冷却状态。
- 卡片操作：测试、编辑、启用/停用、删除；默认配置可清晰标识，并可从卡片或编辑表单设置默认。
- 新增/编辑采用表单对话框或侧边面板；窄屏可滚动，保存、取消和错误提示清楚。
- 删除要求二次确认；若删除默认配置，确认内容明确提示默认配置将变为空。
- 暂停/停用只影响后续使用能力，本期没有模型调用流程，因此不发起后台路由变更。

### 定时任务页

- 在「配置」导航下提供「定时任务」页面。
- 显示「定时任务功能尚未启用」，说明后续可在此管理采集、数据刷新等工作。
- 不显示示例任务、不开放创建按钮、不启动后台调度。

## 数据与技术设计

### 现有架构延续

| 层 | 设计 |
|---|---|
| Web | Next.js App Router、React、TypeScript |
| 部署 | Vercel，Node.js 服务端运行时 |
| 数据库 | Neon PostgreSQL，作为应用业务状态的唯一持久化数据源 |
| ORM/迁移 | Drizzle ORM 与版本化 Drizzle Kit migrations |
| UI | Tailwind CSS 与项目现有组件、浅色后台样式 |
| 认证/加密 | Node.js `crypto` 内置模块；不把秘密交给浏览器 |

实现阶段需依照仓库约定查阅当前安装的 Next.js 官方文档，确认 Next 16 路由保护、Cookie 和 Route Handler 的适用方式。

### 模型配置表

新增 `llm_model_configs` 表，建议字段：

| 字段 | 说明 |
|---|---|
| `id` | UUID 主键 |
| `name` | 卡片展示名称，例如 qwen |
| `base_url` | OpenAI-compatible API 根地址 |
| `model` | 提供方模型标识 |
| `api_key_ciphertext` | AES-GCM 密文，不保存原始密钥 |
| `api_key_iv` / `api_key_auth_tag` | AES-GCM 解密所需参数 |
| `api_key_last4` | 用于掩码展示的末四位 |
| `key_version` | 加密格式/密钥版本标记 |
| `priority` | 正整数；为未来路由预留，本期不执行优先级路由 |
| `timeout_seconds` | 连接测试超时秒数，限制在合理范围内 |
| `reasoning_enabled` | 是否启用提供方支持的深度思考参数 |
| `enabled` | 是否启用 |
| `is_default` | 是否为默认配置；至多一个启用配置可为默认 |
| `last_test_status` / `last_tested_at` | 最近一次连接测试状态和时间 |
| `last_test_message` | 已清理敏感信息的简短错误摘要 |
| `created_at` / `updated_at` | 创建与更新时间 |

数据库以约束保护 `priority`、`timeout_seconds` 的范围，并使用部分唯一索引保证最多一个默认配置。默认配置必须处于启用状态。允许没有默认配置，例如尚未配置或管理员停用了当前默认配置。

登录限流表仅存不可逆标识摘要和失败时间，不保存原始 IP 或密码。只保留短时间窗口内的记录，并在登录处理时清理过期记录。

### 服务端秘密与登录会话

新增以下服务端环境变量，更新 `.env.example` 只放占位说明：

- `ADMIN_USERNAME`：单管理员登录名。
- `ADMIN_PASSWORD_HASH`：使用 Node.js scrypt 派生的密码哈希及盐，不存明文密码。
- `AUTH_SESSION_SECRET`：至少 32 字节的随机会话签名秘密。
- `MODEL_API_KEY_ENCRYPTION_KEY`：32 字节 AES-256-GCM 加密密钥，以十六进制形式保存。

本地与 Vercel 配置文档说明如何生成这些值；实际秘密由管理员在环境变量管理界面配置，不提交到仓库。密码哈希生成工具要求至少 12 位密码，并避免在终端回显明文。缺少必需变量时，认证必须失败关闭；登录/保存配置功能明确报出缺少的配置名，但不得打印秘密值。

成功登录后设置签名会话 Cookie：`HttpOnly`、`SameSite=Strict`、`Path=/`，生产环境启用 `Secure`；会话有效期为 8 小时，并支持退出时清除。验证签名时使用恒定时间比较。登录失败按来源地址 HMAC 摘要限流，15 分钟内 5 次失败后暂时拒绝继续尝试；不持久化原始 IP。应用不提供公开注册或账户恢复流程。

所有业务页面、现有商品 API 及新配置 API 均须在服务端独立验证管理员会话。不能仅依赖导航隐藏、客户端状态或页面跳转保护。写请求再校验同源请求来源，避免跨站提交。

### API Key 加密与脱敏

- 使用 `aes-256-gcm`；每次加密生成独立随机 IV，并保存认证标签。
- 仅服务端密钥服务能够加密/解密。日志、错误追踪、API 响应和 HTML 均不得包含原始 API Key、密文、IV 或认证标签。
- 列表和详情 API 只返回脱敏后的 `••••末四位`、是否已配置以及非敏感模型参数，不返回密文。
- 编辑提交中的 key 为空时不修改当前密钥；提交新 key 时在数据库事务中更新密文和末四位。
- 加密密钥缺失或解密校验失败时拒绝保存/测试并给管理员明确的服务端配置错误提示，不回退为明文存储。
- 账号环境密钥更换需要专门的重加密流程；本期不提供无提示的密钥轮换或静默解密降级。

### 模型连接测试与 SSRF 防护

- 测试由受会话保护的服务端 API 发起，浏览器只收到脱敏后的成功/失败结果。
- 仅允许 HTTPS、标准端口、无 URL 用户信息的公共主机名；拒绝 localhost、私有/保留 IP、内网域名和非 HTTPS 地址。
- DNS 解析后校验目标为公共地址，并将校验后的地址用于实际连接；TLS 仍校验原始主机名证书。不跟随重定向，避免经跳转访问内部服务。
- 请求严格使用已配置的模型、服务端解密后的 API Key 和表单超时上限；失败消息清除响应体中的凭据、请求头与敏感内容。
- 测试 OpenAI-compatible Chat Completions 接口，使用最小请求量。保存配置不会自动调用外部模型；只有点击「测试」才产生外部请求。
- 测试成功仅表示该时间点连接成功，不代表模型的全部能力、配额或后续可用性。

## 数据 API 轮廓

所有配置 API 均要求有效管理员会话：

- `GET /api/settings/models`：返回脱敏后的配置卡片数据。
- `POST /api/settings/models`：校验并创建配置，服务器加密 API Key。
- `GET /api/settings/models/:id`：返回单项脱敏配置。
- `PATCH /api/settings/models/:id`：更新允许编辑的字段；密钥按空值保留/新值替换规则处理。
- `DELETE /api/settings/models/:id`：删除指定配置。
- `POST /api/settings/models/:id/test`：使用存储的密钥执行连接测试并记录结果。
- 登录由限流的认证 Route Handler 处理；退出要求有效会话并清除会话 Cookie。

API 输入在服务端使用 schema 校验，数据库访问使用参数化 Drizzle 查询。优先级、超时、URL、模型名及枚举值均不得只依赖浏览器校验。

## 空、错误与加载状态

- 未登录：跳转登录；API 返回一致的未认证响应，不回显内部细节。
- Neon 不可用：页面展示清晰的数据库连接错误，不伪造默认模型或任务数据。
- 没有模型配置：显示空状态和「添加模型」入口。
- 未测试/测试成功/测试失败：使用清晰标签；失败信息简洁并经过脱敏。
- 加密密钥缺失、密钥解密失败、URL 被安全策略拒绝、请求超时和服务商拒绝认证分别给出可理解提示。
- 表单保存期间防重复提交；服务器字段错误显示在对应输入附近。
- 所有状态均适配键盘操作、清晰焦点、读屏表单名称及窄屏布局。

## 验收标准

1. 未登录用户无法读取或修改商品模型、商品数据、模型参数以及相关 API 数据。
2. 管理员可登录、退出；错误凭据受到限流，Cookie 具有规定的安全属性。
3. 模型参数页面以符合参考图方向的响应式卡片显示真实 Neon 配置。
4. 管理员可新增、读取、编辑、启用/停用、设为默认、删除模型配置；默认配置唯一且不能被停用后仍标为默认。
5. API Key 在 Neon 中只以 AES-GCM 密文保存；列表、详情、HTML、日志和错误响应不泄露原始 key 或密文；编辑留空保留旧 key，输入新 key 可安全替换。
6. 连接测试由服务器发起，可正确展示成功、认证失败、超时和不安全 URL 等结果；测试过程不跟随重定向，并阻止私网目标。
7. 保存配置不自动请求模型；本期不出现模型聊天、优先级路由或自动冷却行为。
8. 定时任务菜单可进入空状态页面，不展示伪造任务且不启动调度。
9. Neon 迁移和 Vercel 环境变量文档覆盖新增配置；没有 Neon 时显示可理解错误且不切换到本地模拟数据。

## 设计自审

- 已把认证保护扩展到现有商品 API，避免只保护新增模型设置页而遗留公开数据入口。
- 已明确 Neon 保存业务状态，服务端环境变量保存认证和加密秘密；两类数据职责不同。
- API Key 仅由服务端加解密，GET 响应不含密文，编辑空值不会误清除密钥。
- 连接测试对自定义 URL 的 HTTPS、公共地址、重定向和超时作出明确限制，覆盖主要 SSRF 风险。
- 优先级、深度思考和冷却展示没有被误表述为已实现的模型路由/调度能力。
- 定时任务为明确的空状态，避免生成虚假数据。
- 新 UI 延续现有应用导航和浅色设计，并适配小屏与键盘访问。
